# depgraph — граф зависимостей Maven-пакета

Практическая работа №2, «Конфигурационное управление», вариант 9.
Инструмент строит граф зависимостей Maven-пакета без менеджеров пакетов
и сторонних библиотек (только стандартная библиотека Python 3.10+).

Документ дополняется по мере выполнения этапов.

## Настройки (INI)

См. `examples/maven-central.ini`.

| Параметр | Описание |
|----------|----------|
| `package` | Имя пакета `groupId:artifactId:version` (в тестовом режиме — заглавные латинские буквы) |
| `repository` | URL репозитория или путь к файлу тестового репозитория |
| `test_mode` | `true` / `false` — режим работы с тестовым репозиторием |
| `filter` | Подстрока: пакеты, в имени которых она есть, не анализируются |

## Запуск

```sh
./run.sh --config examples/maven-central.ini --show config
make test
```
